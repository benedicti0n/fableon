# Phase 2.6 — Provenance

## Artwork status

**DIAGNOSTIC ARTWORK — NOT ARTISTIC VALIDATION.**

No premium source artwork was present in the repository. The benchmark source is
the Phase 2.5 procedural storybook bird and forest, generated by repository code
and then re-imported through the Phase 2.6 PNG inspection, trim, hash,
registration, pack, and rig-adapter pipeline.

No external illustration, photograph, AI image, font asset, model output, or
paid provider was used. No credentials were added.

## Source pipeline

1. `createStorybookBirdArt(seed = 20261109)` paints nine transparent part
   canvases.
2. `createLandingSceneArt(seed = 20261109)` paints the forest plate.
3. Each diagnostic canvas is encoded as PNG.
4. `prepareImageBlob` decodes, inspects alpha, computes SHA-256 source and
   prepared hashes, trims fully transparent padding at threshold 0, and encodes
   the prepared PNG derivative.
5. The prepared parts are assigned to the nine-part storybook-bird template with
   source-space pivots and registration.
6. `createImportedCharacterRig` maps the pack onto the existing Phase 2.5 landing
   rig without repainting pixels.
7. The benchmark composes the imported character over the imported single-plate
   environment and runs the same 48-frame motion.

The full sequence is generated by:

```bash
pnpm benchmark:phase-02-6
```

The command requires Playwright Chromium and local `ffmpeg` with H.264 support.
It writes 48 actual 1920×1080 PNG frames, selected frames, contact sheet,
fidelity comparison, source/prepared previews, validation JSON, performance
JSON, and an MP4. No GIF was produced for Phase 2.6; the MP4 is the playable
preview.

## Measured fidelity

From the captured `performance.json`:

- Every prepared part matches its source crop with mean absolute error **0**.
- The imported environment plate matches the source plate with mean absolute
  error **0**.
- Full-frame baseline-to-imported mean absolute error at frame 47:
  **0.0002318** (on a 0–255 channel scale).
- Full-frame changed-pixel ratio at frame 47: **0.00386%**.
- Foot lock and repeated-evaluation checks pass.

These values are environment-local pixel comparisons, not universal guarantees.
PNG encoding is pixel-equivalent rather than byte-identical across browsers.
