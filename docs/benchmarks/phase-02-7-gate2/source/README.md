# Fableon Gate 2 — Repaired Candidate v2 (not approved)

This is a **visual registration prototype**, not a production-ready character pack and **not a validated fableon.illustration-pack v1 export**.

## What changed
- The torso `assets/premium-bird-v1/parts/body.png` was reconstructed without the baked blue wing.
- The head `assets/premium-bird-v1/parts/head.png` was reconstructed without a baked eye/beak.
- The remaining seven parts were retained from the earlier candidate cutouts.
- Real RGBA PNGs were created from image-board artwork using estimated saturation mattes.
- Five pose previews, a contact sheet, and a 48-frame registration-motion test were rendered.

## What is NOT solved
- The generated board is not a layered source; feather details and hidden anatomy are inferred, not a faithful reveal of occluded pixels.
- Current source sprites range from 45px to 266px wide. These assets are **not** full-HD production artwork.
- Body/head styling is similar but not perfectly source-matched; separate part placement is provisional.
- Seams, feather edges, wing anatomy, and body/leg contacts need human review.
- The test animation is generated by `rebuild.py` using PIL, not by Fableon's repository pipeline.
- The package does not contain an actual Fableon illustration-pack v1 manifest and must not be treated as passed through `/studio/assets`.

## Next action
Use pose-contact-sheet.png and registration-motion-test.mp4 to identify which sprites require further source artwork; then import a production artist-authored part set into Fableon's actual `/studio/assets` before authorizing Phase 3.

## Reproduce the preview after extraction

Requires Python 3 with Pillow and `ffmpeg` on PATH:

```bash
python3 -m pip install Pillow
python3 preview_generator.py
```

This regenerates the five pose PNGs, the contact sheet, 48-frame local test sequence and MP4 using **the included part PNGs**. The test scene is 960×540; it is not a source-resolution proof.
